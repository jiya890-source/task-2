# HR Candidate Email Response Tool

A simple web application for HR teams to send professional email responses to job candidates.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP

## Features

- Candidate selection status
- Candidate name, email and position input
- Form validation
- Selection and rejection email templates
- Email preview
- PHP email sending
- Responsive design

## How to Run

1. Install and open XAMPP.
2. Start Apache.
3. Copy the Task2 folder into:

C:\xampp\htdocs\

4. Open this URL in your browser:

http://localhost/Task2/

## Email Settings

The application uses PHP's `mail()` function.

For local testing, a mail server/SMTP configuration may be required.
